ERBIOBENCH — SCORER V3 MATCHING FIX FREEZE
Date: 2026-10-17

Reason for revision
-------------------
An audit of score_llm_response_v2.R identified two objective issues
affecting biological agents without a canonical agent_id.

1. AGENT IDENTIFICATION

v2 constructed the gold agent set only from non-null agent_id values.
Consequently, unresolved or synthetic agents with agent_id = NULL could
be omitted from a response without being penalized in the
agent_identification domain.

2. REGULATORY / REFERENCE LEVEL MATCHING

For gold agents with agent_id = NULL, v2 matched response agents by exact
agent_name string. This generated false negatives when the same scientific
entity was described with additional explanatory wording.

SCORER V3
---------
score_llm_response_v3.R implements conservative hierarchical matching:

- exact canonical agent_id when an ID exists;
- for agents without agent_id, matching requires a response agent also
  without canonical ID and agreement on structural regulatory properties;
- no fuzzy name matching is used;
- unresolved reference_level must remain unresolved;
- regulatory_minimum_group must agree when specified;
- agent identification now requires all gold agents, including agents
  without canonical IDs, to be represented.

INTERPRETATION
--------------
The v3 change is a scoring correction, not a modification of any model
response or ERBioR reference output.

It simultaneously:
- removes false-positive scoring of omitted unresolved agents in C1/C2;
- removes a false-negative regulatory score in O3/P15/C3.

No API calls or model reruns were used to obtain the corrected scores.
