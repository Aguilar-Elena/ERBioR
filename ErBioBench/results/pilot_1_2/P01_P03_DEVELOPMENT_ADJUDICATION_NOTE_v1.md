# ERBioBench P01-P03 development adjudication checkpoint

This checkpoint contains 90 technically valid responses from ERBB-P01 to ERBB-P03.

The 82-point deterministic component was produced by the frozen automated ERBioBench scorer.

The remaining 18 points comprise:
- Preventive actions: 0/5/10 points
- Traceability/coherence: 0/4/8 points

IMPORTANT: the 18-point adjudication in this checkpoint was performed by an LLM assistant acting as a development adjudicator (ADJUDICATOR_A).

These scores MUST NOT be described as human, expert-human, or final manual adjudication in a publication.

For publication-final analyses, a separate human-adjudication dataset should be created without overwriting this development checkpoint. Preferably, two independent human occupational-health/biological-risk experts should adjudicate blinded responses, followed by inter-rater agreement analysis and consensus.

Development results are retained for rubric testing, pipeline validation, sensitivity analysis and comparison with subsequent human adjudication.
